# Costly-branch development probes

These six synthetic scenarios are development probes, not release efficacy evidence. They contain three costly unresolved decisions, one resolved decision, one shared reversible step, and one private disposable sample. The high-cost context must not by itself turn either cheap control into an interview.

Before the first model run, freeze this corpus in Git. Send the initial prompt verbatim, resume with the frozen follow-up where present, and use the existing candidate-bound runner with no primary retry. Check the first move and final delivery separately. Questions must address the consequential unresolved requirement; an adjacent input or tone question earns no credit. Final requirements are exact excerpts from the user-visible turns. No actual telemetry, venue, contract, private prompt, or external execution is involved.

Acceptance for this development instrument: each of the three costly cases asks at most one primary question before committing a branch; all three controls deliver without an intent question; resolved follow-ups honor the selected outcome and output constraints; no domain tool or user-work action occurs. Preserve failures without rewriting their requirements to fit outputs.

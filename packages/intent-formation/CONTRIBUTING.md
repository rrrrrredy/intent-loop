# Contributing

Preserve the experience-first boundary in AGENTS.md.

Before proposing a change:

1. Add or update a positive, negative, or boundary scenario.
2. Run npm test.
3. State the user-visible behavior that changed.
4. Separate implementation evidence from any claim about user outcomes.

Do not add prompt or transcript persistence. Keep state sparse and subordinate to the interaction. Do not add another host, rich UI, autonomous long-term learning, or marketplace publication until the product gate in docs/evaluation-plan.md has passed.

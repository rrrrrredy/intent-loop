# Support

For usage questions and reproducible defects, [open a GitHub issue](https://github.com/rrrrrredy/intent-loop/issues). Search existing issues first and use synthetic data.

Include the product version, host, operating system, Node.js version, exact command, expected result, and sanitized output. Do not paste prompts, credentials, task identifiers, ledger contents, private paths, or exported intent records.

For suspected vulnerabilities, follow [SECURITY.md](SECURITY.md) and use private reporting.

DeepSeek Harness is a developer preview. When reporting adapter breakage, include the exact `@deepseek-ai/dsh` version and whether the failure occurs during add, compose, boot, tool use, or removal.
